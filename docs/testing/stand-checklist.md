# Чек-лист стенда

Автоматическая часть: `STAND_URL=https://… backend/scripts/stand_checklist.sh`; сетевой smoke: `STAND_URL=https://… pytest backend/tests/smoke -q`.

| # | Проверка | Как | Статус |
|---|---|---|---|
| 1 | Адрес по HTTPS | скрипт | ☐ |
| 2 | `GET /health` → 200 за < 2 с | скрипт, smoke | ☐ |
| 3 | `GET /me` без токена → 401, формат каталога, без стека | скрипт, smoke | ☐ |
| 4 | `.env` не в git и в `.gitignore`, токен бота не в истории | скрипт | ☐ |
| 5 | Права на `.env` 600 | скрипт | ☐ |
| 6 | `pg_dump` создаёт непустой файл (`PG_DUMP_CMD`) | скрипт | ☐ |
| 7 | Вход из Telegram с телефона, выбор роли | вручную | ☐ |
| 8 | Адрес Mini App указан у бота в BotFather | вручную | ☐ |
| 9 | Откат: предыдущий релиз поднимается | вручную | ☐ |

Заполняется после появления стенда (задача менеджера «Стенд»).
