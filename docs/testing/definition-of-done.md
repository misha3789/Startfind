# Definition of Done

Задача считается выполненной, только если выполнено всё:

1. Код влит в `main` через PR; ревью сделал **другой** участник.
2. CI зелёный: `ruff check` без замечаний, `pytest` на PostgreSQL проходит.
3. Для новой логики есть тесты: норма, граница, ошибка (код из каталога `docs/testing/error_codes.md`).
4. Проходят `alembic upgrade head` и `downgrade base` (если менялась БД).
5. Ошибки отдаются в едином формате `{code, message, request_id}`; в ответе нет стека.
6. Нет секретов, `.env`, токенов, персональных данных в репозитории и истории.
7. Обновлены документация и критерии приёмки, если поведение изменилось.
8. Коммиты от имени автора, сообщения по `docs/CONTRIBUTING.md`; использование ИИ записано в `docs/ai-usage.md`.
9. Найденные дефекты занесены в `docs/testing/defects.md` (серьёзность, шаги, владелец).

Приёмка этапа 1: чистая установка (`backend/scripts/clean_install_check.sh`), upgrade/downgrade, чек-лист ниже.
