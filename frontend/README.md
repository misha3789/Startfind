# Frontend (Mini App)

React + Vite + Telegram WebApp SDK.

```
cd frontend
cp .env.example .env
npm install
npm run dev      # http://localhost:5173
```
Вне Telegram приложение открывается как обычная страница (имя пользователя — «Гость»).
Для проверки внутри Telegram нужен HTTPS-туннель (см. docs/botfather-setup.md).
